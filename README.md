# RoWave AI — Roblox Game Builder

Free AI-powered platform to build complete Roblox games.

## Features

- **Google Login**
- **Roles**: Member → Mod → Admin → Owner → Founder
- **Founder emails** auto-promoted:
  - shadyeliteyt@gmail.com
  - DEVNOFAME@gmail.com
  - adamjcocolin@gmail.com
  - bixmail.es@gmail.com
- **100 daily credits** (reset 12 AM EST) — founders/admins unlimited
- **AI Builder** chat (code, GUI, Blender)
- **Support AI**
- **Group / Game / Profile Analyzer**
- **Servers**, **Marketplace**, **Find Developers**
- Theme: **Red · White · Black**

## Setup

```bash
npm install
cp .env.example .env.local
# fill Google + NextAuth secrets
npm run dev
```

## Deploy

Connected to Vercel. Push to `main` to deploy.
